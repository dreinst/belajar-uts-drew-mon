2. Fungsi satu per satu

  
Ketik input, lihat output. Coba nilai aneh seperti 7O, 10,6, -3, NaN, atau 1e2.

  

    

      
"teks".toIntOrNull()

      
Dipakai untuk usia. Hasil null berarti bukan bilangan bulat, lalu muncul pesan "Isi dengan angka bulat".

      
      

    

    

      
GrowthValidator.parseDecimal(text)

      
Dipakai untuk berat dan tinggi. Koma diganti titik dulu, NaN dan Infinity ditolak.

      
      

    

    

      
Validasi kode anak

      
trim(), uppercase(), lalu dicek kosong, panjang, dan pola ^[A-Z0-9-]+$.

      
      

    

    

      
formatDiff(diff, unit)

      
Selisih dibulatkan satu desimal, lalu diberi tanda ▲, ▼, atau =.

      

      

    

    

      
formatDecimal(value)

      
Format angka Indonesia, satu angka di belakang koma.

      
      

    

    

      
Berat atau tinggi: urutan cek

      
Isi teks, pilih kolom. Urutan when: kosong, bukan angka, tidak positif, di luar batas.

      

      

    

  









  
3. Latihan live modification

  
Contoh perubahan yang biasa diminta dosen saat defense. Edit kode Kotlin di kotak gelap, lalu tekan Periksa. Kalau benar, perubahan langsung diterapkan ke sandbox di atas supaya hasilnya terlihat. Setelah lancar di sini, coba lakukan hal yang sama di Android Studio.

  

    Alur kerja live modification
    
    
      
  1. Buka repo di Android Studio. Andrew: ~/ndru/GrowthEduTrack. Monica: ~/Downloads/GrowthEduTrack. Keduanya clone dari github.com/dreinst/uts-mobile-ht-07-growthedutrack, branch main.
    2. 
      
  2. Cari file. Semua kode ada di bawah app/src/main/java/id/ac/machung/growthtrackedu/, unit test di app/src/test/java/id/ac/machung/growthtrackedu/. Cara cepat: tekan Cmd+Shift+O (Mac) atau Ctrl+Shift+N (Windows), lalu ketik nama file. Untuk lompat ke baris tertentu: Cmd+L atau Ctrl+G.
    3. 
      
  3. Ubah semua file yang disebut di kotak "Lokasi file" pada latihan, termasuk unit test. Kalau test tidak ikut diubah, ./gradlew testDebugUnitTest akan gagal.
    4. 
      
  4. Cek hasilnya: Run app di emulator atau HP, lalu jalankan unit test (klik kanan app/src/test, Run Tests).
    5. 
      
  5. Saat latihan, jangan commit. Batalkan semua perubahan dengan:
    git restore .
    Repo kembali sama seperti di GitHub dan jumlah commit tetap 12.
    6. 
      
  6. Kalau dosen minta perubahannya disimpan, commit di repo yang sama (branch main) memakai pesan commit dari kotak latihan, lalu push:
    git add -A
git commit -m "pesan commit dari kotak latihan"
git push
    Commit ini menambah jumlah commit menjadi 13 dan seterusnya. Itu tidak melanggar PDF karena syaratnya minimal 12.
    7.
