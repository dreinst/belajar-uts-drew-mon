# Belajar UTS GrowthTrack Edu (HT-07)

Situs latihan untuk Andrew dan Monica sebelum defense UTS Pemrograman Bergerak.

- Sandbox aplikasi: tiruan layar UTS dengan jejak cabang `when` di GrowthValidator.
- Fungsi satu per satu: input dan output `toIntOrNull`, `parseDecimal`, `formatDiff`, dan lainnya.
- Live modification: 7 latihan beserta lokasi file di repo `uts-mobile-ht-07-growthedutrack` dan pesan commit.
- Kuis defense: 26 soal dengan filter per anggota.

Pilih profil Andrew atau Monica di awal. Setiap profil punya kartu "Fokus kamu" (commit, file yang dipegang, urutan belajar), latihan miliknya tampil lebih dulu, dan progres latihan serta kuis disimpan terpisah di browser. Situs ini satu file `index.html` tanpa build step.
